# Timezone Rules

- **CRITICAL**: Always use `America/Caracas` as the timezone when generating reports, saving records, making backups, or returning dates/times in the backend and frontend for the valet-eye project. This is the official project timezone. Do not use local, Madrid, or any other timezone unless explicitly asked.
